ol-copc/source/COPC~COPCSource 


import COPCSource from 'ol-copc/source/COPC.js';

A source for Cloud Optimized Point Clouds (COPC), to be rendered with a COPCLayer. Loads the metadata and the octree hierarchy, the points are decoded in web workers.
