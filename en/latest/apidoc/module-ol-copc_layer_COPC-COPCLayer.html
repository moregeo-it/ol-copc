Class: COPCLayer

This documentation is for OL COPC v0.1.0. The latest is v.

ol-copc/layer/COPC~COPCLayer 


import COPCLayer from 'ol-copc/layer/COPC.js';

A layer that renders a Cloud Optimized Point Cloud (COPC) with WebGL 2, top-down or in an oblique (tilted) view that follows the rotation of the map.

The COPC source.
tilt number (defaults to 0)

The tilt of the view in degrees, up to 75. Points are shifted towards the top of the screen by their height above the ground (oblique view).
groundElevation number | undefined

The elevation that is not shifted by the tilt. Estimated from the point cloud by default.
pointSize number (defaults to 2)

The size of the points in CSS pixels. The level of detail is chosen so that the points are about this far apart.
pointBudget number (defaults to 3000000)

The maximum number of points to render.

The maximum number of points kept on the GPU.
